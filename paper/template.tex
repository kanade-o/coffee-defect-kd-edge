\abstract{Manual inspection of defective green coffee beans is labor-intensive and often inconsistent. 
This study presents an edge-oriented defect detection system that applies knowledge distillation from high-capacity deep learning teacher models to a lightweight student model. 
Using an original dataset of 72,000 images, the distilled student outperforms the standalone student in all classification metrics while maintaining real-time inference (about 9 ms per image) on a Raspberry Pi 5. 
These results show that knowledge distillation enables the construction of a lightweight, fast, and high-performance defect detection model on edge devices.}

\section{はじめに}
\vspace{-3mm}
コーヒー生豆の欠点豆とは, 欠け・発酵・未熟・虫食いなど, 焙煎後のコーヒーの風味を低下させる豆を指す. 
現在主流の選別作業は, 人手による目視で欠点豆を取り除く方法であり, 生産地や自家焙煎を行う店舗で広く用いられている. 
しかし, この手動選別は労働集約的で時間がかかるうえ, 作業者ごとに判断にばらつきが生じ, 一貫性や正確性に課題がある~\cite{1}. 

こうした課題に対し, CNNを用いた画像分類モデルや, Raspberry Pi上での欠点豆識別など, 深層学習とエッジコンピュータを用いた自動検査・選別に関する研究が報告されている~\cite{1}~\cite{2}. 
また, 知識蒸留を利用して, 大規模CNNモデルの知識を軽量モデルへ転移し, 性能をある程度維持しつつモデルサイズやメモリ使用量を削減する手法も提案されている~\cite{4}. 
しかし, コーヒー生豆欠陥検出における最適な教師モデルや教師・生徒の組み合わせ, および推論速度やCPU・メモリ使用率を含むエッジ上での実用性は十分に検討されていない. 

本研究の目的は, 深層学習と知識蒸留を活用して, コーヒー生豆の欠陥を高速かつ高性能に検出できるエッジコンピュータ向けの欠陥検出システムを構築し, その際の教師モデル・生徒モデルのアーキテクチャの違いが性能と実用性に与える影響を明らかにすることである.

\section{提案手法について}
  本研究では, 知識蒸留に基づく教師と生徒モデル構成を採用した. 
  知識蒸留とは, 大規模な教師モデルの出力分布を学習目標とすることで, 小型の生徒モデルに教師の判断傾向を模倣させる手法である. 
  これにより, 生徒モデルはパラメータ数や計算量を抑えつつ, 教師モデルに近い識別性能を獲得することが期待される. 

  まず, CNNベースとTransformerベースから複数の最先端モデルを教師候補として比較し, 欠点豆の見逃しを抑えることを重視した教師モデル選択を行った. 
  これらの教師モデルに対し, Raspberry Pi 5などのエッジコンピュータ上での動作を想定した軽量な自作CNNを生徒モデルとして設計し, それぞれから生徒モデルへの知識蒸留を行った.

\section{データセットについて}
データセットは, 本研究で独自に収集したコーヒー生豆画像から構築した. 
まず, 人手によってラベル付けした良豆1,000枚と, 欠け・奇形・カビなど確実に欠点豆と判断できる欠点豆1,000枚を取得し, 合計2,000枚の元画像を用意した. 
画像サイズは224x224ピクセルに統一し, タスクは良豆と欠点豆の2値分類とした. 
また, モデルの汎化性能を高めるため, これらの元画像に対して40度ごとの回転および上下左右の反転によるデータ拡張を行った. 
その結果, 良豆・欠陥豆それぞれ36,000枚, 合計72,000枚からなるデータセットを構築できた. 

\section{結果と考察}
まず, 教師候補モデルとして, CNNベースとTransformerベースモデルの最先端モデルをそれぞれ比較した.  
本研究では欠点豆の見逃しを抑えることを重視し, Recallを最優先指標としたため, 高いRecallとF1-scoreを両立したResNet-50およびSwin-Smallを教師モデルとして採用した.  

次に, これらの教師モデルから軽量CNN生徒モデルへの知識蒸留を行い, 生徒モデル単体との性能比較を行った.  
表\ref{tab:kd_results}に, 各モデルの分類性能を示す.  
ResNet-50を教師とした場合, 知識蒸留後の生徒モデルは, 生徒モデル単体と比較して全ての指標で性能が低下した.  
一方, Swin-Smallを教師とした場合, 知識蒸留後の生徒モデルは全ての評価指標において生徒モデル単体を上回る性能を示した.  

以上の結果から, 本研究ではTransformerベースのSwin-Smallを教師モデルとすることで, 知識蒸留により軽量な生徒モデルが元の生徒モデルを上回る性能を達成できたことが分かる.  
これは, 教師モデルのアーキテクチャ選択が知識蒸留の効果に大きく影響することを示唆している.  

さらに, エッジコンピュータ上での実用度の評価として, Raspberry Pi 5上で各モデルの推論性能を測定した.  
その結果, Swin-Smallおよび ResNet-50といった教師モデルは, 平均推論時間がそれぞれ364.7ms(約2.7FPS), 226.6ms(約4.4FPS)と長く, リアルタイム処理には不適であった.  
一方, 軽量な生徒モデルは平均9ms程度(約110FPS)と高速であり, エッジコンピュータ上でも十分なリアルタイム性を有していた.  
知識蒸留を適用した生徒モデルは, 精度向上を維持しつつ推論時間にほとんど影響を与えず, 生徒モデル単体と同等の高速性を示した.  
以上より, 知識蒸留を用いた軽量モデルは, エッジコンピュータ上でのリアルタイム欠陥検出に有効であるといえる.  

\section{終わりに}
本研究では, コーヒー生豆の欠陥検出を対象として, 深層学習と知識蒸留を用いたエッジコンピュータ向け欠陥検出システムの構築を行った. 
その結果, 独自に構築したデータセットに対して高い分類性能を示すことができた.

今後の課題としては, まず, さらなる汎化性能の向上を目指して, 画像の追加収集によるデータ量を増加をさせる. 
また, 欠陥クラスを細分化した多クラス分類へ拡張することで, より厳しいタスクでの評価が可能になると考えられる. 
さらに, 教師モデルの中間層特徴を利用する知識蒸留手法を導入することで, 表現能力の高い特徴を軽量な生徒モデルへ効果的に転移し, より困難なタスクにおいても高性能を維持できるシステムの構築を目指す.
