\chapter{序論} \label{chap:jyoron}

\section{研究背景}%\label{sec:background}
コーヒー生豆における「欠点豆」とは, 欠け, 発酵, 未熟, 虫食い, カビなど, 焙煎後の風味や香りを著しく低下させる欠陥を有する豆を指す. 
これらの欠点豆が一定割合以上混入すると, 焙煎後の品質が悪化し, スペシャルティコーヒーをはじめとする高品質コーヒーのブランド価値や安定供給を損なう直接的な要因となる. 
そのため, 生産地の輸出業者や自家焙煎を行う店舗においては, 焙煎の前段階で欠点豆を確実に取り除く選別工程が不可欠である.

現在, 多くの現場で行われている欠点豆選別は, 人手による目視検査に依存している. 
これは作業者がトレー上の豆を一粒ずつ観察し, 欠点豆と判断したものを手作業で除去する方法であるが, 労働集約的であり, かつ熟練を要する作業である. 
この手法には, 作業者ごとの判断基準の違いや疲労により, 選別精度にばらつきが生じやすく, 一貫した品質管理が困難であるという課題がある~\cite{pinto2017classification}. 
さらに, 多数の豆を処理するには膨大な時間的コストを要するため, コーヒー需要の増加に伴い, 自動化・省力化に対するニーズは急速に高まっている.

近年, 深層学習技術の発展に伴い, 畳み込みニューラルネットワーク(CNN)を用いてコーヒー生豆の画像から欠点豆を自動検出する研究が多数報告されている~\cite{pinto2017classification, huang2020smart, wang2021deep}. 
これらの研究では, 画像分類モデルを用いることで, 熟練者の目視に近い, あるいはそれを上回る精度で良豆と欠点豆を判別できる可能性が示されている. 
また, 実際の生産現場や小規模ロースターでの運用を想定し, Raspberry Piのような低コストなエッジデバイス上で選別システムを構築する試みも報告されている~\cite{fukai2018classification}.

しかし, 深層学習モデルをエッジデバイス上で実運用するには, 単に分類性能が高いだけでは不十分である. 
エッジデバイスは計算資源(CPU, メモリ)や電力に制約があるため, 大規模なモデルをそのまま搭載すると推論遅延が発生し, 選別ラインの速度に追従できない問題が生じる. 
これに対し, モデルのパラメータ数を削減しつつ性能を維持する手法として, 知識蒸留(Knowledge Distillation)が知られている~\cite{hinton2015distilling}. 
コーヒー豆検査の文脈においても, モデルの軽量化や効率化に関する検討はなされているものの~\cite{wang2021deep}, エッジデバイス上でのリアルタイム性を最優先とした場合の最適なモデル設計については十分な議論がなされていない.

特に, 知識蒸留においてどの教師モデル(Teacher Model)を用いるかが, 軽量な生徒モデル(Student Model)の性能に与える影響については未解明な点が多い. 
近年, 画像認識分野ではCNNに代わりVision Transformer(ViT)が台頭しているが, コーヒー生豆の欠陥検出において, 従来のCNNとViTのどちらを教師とすべきか, またその選択がエッジデバイス上での推論速度やリソース消費にどう影響するかを体系的に評価した研究は私たちの調べる限り見当たらない.

\section{関連研究}
伝統的な画像処理技術に代わり, CNNを用いたコーヒー生豆の欠陥分類は高い有効性が確認されている. 
Pintoら~\cite{pinto2017classification}は, ブラジル産のコーヒー豆画像を対象にCNNを適用し, 欠けや虫食いなどの欠陥の種類を高精度に分類できることを示した. 
また, Huangら~\cite{huang2020smart}は, スマート農業の文脈において, CNNを用いたリアルタイム分類システムの構築を提案しており, 選別作業の自動化が農業生産性の向上に寄与することを論じている. 
Wangら~\cite{wang2021deep}は, より高度なCNNアーキテクチャを用いた検査手法を提案し, 欠陥検出の精度向上とモデルの効率化について検討を行っている. 
これらの研究は主に分類精度の向上に焦点を当てているが, 実際の選別現場で求められるハードウェア制約や処理速度とのトレードオフについては, 議論の余地が残されている.

自動選別システムを小規模農園や店舗へ普及させるためには, 高価なGPUワークステーションではなく, 安価で小型なエッジデバイスでの動作が必須となる. 
Fukaiら~\cite{fukai2018classification}は, Raspberry Piとカメラモジュールを組み合わせた低コストな選別システムを試作し, CNNを用いた推論を実装した. 
この研究により, エッジデバイスでも欠点豆の識別が可能であることが示されたが, 複雑なCNNモデルをエッジ上で動作させた場合の推論遅延が課題として挙げられる. 
リアルタイムに流れる豆を選別するためには, 数十〜数百ミリ秒単位の高速な応答速度が求められるため, モデルの大幅な軽量化が不可欠である.

エッジデバイス向けのモデル軽量化手法として, 知識蒸留(Knowledge Distillation)が広く用いられている. 
これは, 大規模で高性能な「教師モデル」の出力分布(ソフトラベル)を, 小規模な「生徒モデル」に学習させることで, 教師の持つ知識を転移させる手法である~\cite{hinton2015distilling}. 
一般的に, 教師モデルと生徒モデルは同じアーキテクチャ(例: CNN同士)であることが多いが, 近年では異なるアーキテクチャ間(例: TransformerからCNN)での蒸留効果も注目されている. 
しかし, コーヒー生豆のような特定のドメインデータにおいて, CNNとTransformerのどちらが教師として適しているか, またその組み合わせがエッジデバイスでの推論効率にどう寄与するかを比較検証した事例は報告されていない. 
本研究では, この点に着目し, エッジデバイス上での実用性を最大化する教師・生徒モデルの構成を明らかにする.

\section{研究目的}
そこで本研究では, Raspberry Pi 5を用いたエッジデバイス環境において, 高速かつ高精度な欠陥検出を実現するシステムを提案する. 
本論文の主な貢献は以下の通りである.

\begin{itemize}
\item 独自に構築した72,000枚規模のコーヒー生豆画像データセットを用い, CNNベース(ResNet)およびTransformerベース(Swin Transformer)の最新モデルの性能比較を行った.
\item 欠点豆の見逃し防止(Recall)を重視した教師モデル選定を行い, 異なるアーキテクチャを持つ教師から軽量CNN生徒モデルへの知識蒸留を実施することで, 教師の構造が生徒の学習効果に与える影響を明らかにした.
\item Raspberry Pi 5上での実機評価を行い, 提案モデルが推論速度, CPU使用率・メモリ使用量の観点でリアルタイム選別システムとして十分な実用性を有していることを実証した.
\end{itemize}

\section{本論文の構成}
本論文の構成は以下の通りである.

第2章では, 本研究で用いる主要な技術について概説する. 
深層学習の基礎から始まり, CNNアーキテクチャ(ResNet, EfficientNet), Transformerアーキテクチャ(ViT, Swin Transformer)について説明する. 
さらに, モデルの軽量化手法である知識蒸留と, エッジコンピューティングの概念について述べる.

第3章では, 本研究で提案するエッジデバイス向け欠陥検出システムの全体構成を示す. 
まず, 欠点豆の見逃し防止を重視した教師モデルの選定方針を述べ, CNNベースおよびTransformerベースの複数のモデルを比較検討する. 
次に, Raspberry Pi 5上での実行を想定した軽量生徒モデルの設計方針を説明し, 知識蒸留の実装方法について詳述する.

第4章では, 本研究で使用するコーヒー生豆画像データセットの構築過程について述べる. 
データ収集方法, アノテーション手法, 物体検出モデルYOLOを用いた画像切り出しと前処理, データ拡張手法, およびデータセットの分割方法について説明する. 
最終的に構築した72,000枚規模のデータセットの詳細を示す.

第5章では, 提案手法の有効性を検証するための実験設定について説明する. 
実験環境の詳細, 分類性能指標(正解率, 適合率, 再現率, F1スコア), およびエッジデバイス性能指標(平均レイテンシ, CPU使用率, メモリ使用量)の定義と測定方法について述べる. 
また, 教師モデルの比較実験, 知識蒸留による生徒モデルの学習, エッジデバイス上での実機評価の手順を示す.

第6章では, 実験結果に基づき, 提案手法の有効性および限界について考察する. 
教師モデルのアーキテクチャが知識蒸留の効果に与える影響を分析し, TransformerベースとCNNベースの教師モデルの比較から得られた知見を述べる. 
また, Raspberry Pi 5上での推論性能とリソース消費の観点から実用性を評価し, 本手法の限界と今後の課題について議論する.

第7章では, 本研究の成果を総括し, 今後の展望について述べる. 
知識蒸留による軽量モデルの開発, エッジデバイスでの実用的な推論性能, 異なるアーキテクチャ間の知識蒸留の有効性といった主要な成果をまとめ, 他の農産物への応用展開やマルチモーダル学習への拡張, コーヒー産業および持続可能な農業への貢献について展望を示す.
